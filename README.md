# Личный трекер целей

Трекер задач, сфер (универ, работа, спорт, IELTS, питание, экзамены), дефицита калорий, пробников IELTS и подготовки к экзаменам. Данные хранятся в Supabase, поэтому их видят и сайт, и виджет на iPhone.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | сам трекер (сайт) |
| `config.js` | адрес проекта Supabase и publishable key |
| `schema.sql` | таблицы и правила доступа для Supabase |
| `widget-scriptable.js` | виджет для приложения Scriptable |
| `icon-180.png` | иконка для экрана «Домой» |

## Настройка

### 1. Supabase (один раз)
1. Зарегистрируйтесь на supabase.com и создайте проект (тариф Free).
2. Откройте **SQL Editor → New query**, вставьте весь `schema.sql` и нажмите **Run**.
3. Откройте **Project Settings → API Keys** и скопируйте **Project URL** и **Publishable key**. Впишите их в `config.js`.
4. Откройте **Authentication → URL Configuration** и впишите в **Site URL** адрес трекера. Тогда ссылка из письма с подтверждением будет вести на трекер.

### 2. Сайт
Сайт размещается на GitHub Pages (`https://<логин>.github.io/<репозиторий>/`). Откройте адрес на iPhone в Safari и нажмите **Поделиться → На экран «Домой»**, затем создайте аккаунт прямо в трекере.

### 3. Виджет
1. Установите бесплатное приложение **Scriptable** из App Store.
2. В Scriptable нажмите **+**, вставьте содержимое `widget-scriptable.js` и заполните три строки сверху: `SUPABASE_URL`, `SUPABASE_KEY`, `TRACKER_URL`. Назовите скрипт «Трекер».
3. В трекере откройте **Цели → Виджет на iPhone → Создать код для виджета** и скопируйте код.
4. Удерживайте палец на экране «Домой», нажмите **+**, выберите **Scriptable** и нужный размер (лучше средний или большой).
5. Удерживайте палец на виджете, выберите **Изменить виджет**: в **Script** выберите «Трекер», в **Parameter** вставьте код, а в **When Interacting** выберите **Open URL**.

Виджет показывает дату, процент выполненных задач за сегодня, список невыполненных задач, дефицит калорий и сколько дней осталось до IELTS и ближайшего экзамена. Нажатие на виджет открывает трекер. iOS обновляет виджет сама, обычно раз в 15–30 минут.

## Безопасность
- Publishable key виден в коде сайта, так и задумано. Читать и менять данные может только тот, кто вошёл в свой аккаунт (правила RLS в `schema.sql`).
- Код виджета даёт доступ только на чтение. Если он попал к кому-то, создайте новый код в трекере: старый сразу перестанет работать.
